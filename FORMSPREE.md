# Configurar Formspree

1. Crea cuenta en https://formspree.io
2. Nuevo formulario → email: **luisacorralcoach@gmail.com**
3. Copia el ID del formulario (ej. `mxyzabcd`)
4. En el proyecto, buscar y reemplazar: `mvzyroqk` → tu nuevo ID

Hay formularios en:

- `/` (home)
- `/contacto`
- `/blog` (newsletter)

Todos usan la misma URL: `https://formspree.io/f/mvzyroqk`

Opcional: crea un segundo formulario solo para newsletter y cambia solo el del blog.
